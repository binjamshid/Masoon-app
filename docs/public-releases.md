# Masoon releases

## Find an official build

Use the Masoon listing for your platform and check the publisher. Apple lists **Abdulrahman Al-Rashdi**, and Google Play lists **binjamshid**. Availability and versions can vary by storefront and distribution track. [App Store](https://apps.apple.com/us/app/%D9%85%D8%B5%D9%88%D9%86/id6790180830) · [Google Play](https://play.google.com/store/apps/details?id=net.binjamshid.masoon)

In the app, open **Settings → Support** to see **Version**. Include that value with your platform, OS version and installation channel in a support request or bug report. [User guide](user-guide.md)

## Identify a public source version

Use the full Git commit ID when reporting a result or sharing a modified build. This public source tree contains the modules listed in the [README](../README.md). Store version numbers and screenshots identify the installed application and do not establish equivalence to a source commit.

## Distributing your fork

Identify your fork, link to the editable source of each covered version, and include the [license](../LICENSE) and [applicable notices](../THIRD_PARTY_NOTICES.md). Record supported platforms, the exact source revision, the test commands you ran and any omitted features. Use your own application identifiers and signing configuration.
