# Development

Start with the [TypeScript planner](../backend/README.md). Its example generates a task stream from local fictional inputs and can be run without platform SDKs. Each native package also includes a focused entry point.

| Goal | Setup |
| --- | --- |
| Change event folding, task identity or curriculum evaluation | [Swift](../apps/ios/README.md), [Kotlin](../apps/android/README.md) or [TypeScript](../backend/README.md) |
| Work on a visible mobile component | [SwiftUI example](../mobile-ui/ios/README.md) or [Compose weekly board](../mobile-ui/android/README.md) |
| Work on event exchange | [Offline sync module](../backend/sync/README.md) and [architecture guide](architecture/README.md) |
| Work on a data format | [Contracts and schemas](../contracts/README.md) |

Run each command from the directory stated in its guide. Package managers may contact their publishers to resolve dependencies on first use. Use fictional accounts and content you may redistribute. External submissions go through a fork and a pull request to this repository’s main branch. [Fork and contribution rules](../CONTRIBUTING.md)
