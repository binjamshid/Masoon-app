# Getting help · المساعدة

| If you need… | Where to go |
| --- | --- |
| Help setting up a plan, recording progress or using the Mushaf | Start with the [bilingual user guide](docs/user-guide.md). For account or app support, email **support@binjamshid.com** or use the support link in Settings. |
| To report an app bug | If you can access the repository, choose **New issue → Bug report**. Give platform, app version, language and steps using a sample plan. Otherwise email support. |
| To correct a verse reference, translation, commentary, curriculum or attribution | Choose **New issue → Content correction** or email support with the edition and reference. See [Content contributions](docs/content-contributions.md). |
| To report a vulnerability or unexpected access to personal information | Follow [Security](SECURITY.md) and contact the maintainer privately. |
| To propose an improvement | Open an issue describing who needs the change and what they should be able to do. |

للمساعدة في استخدام مصون، راجع [دليل الاستخدام](docs/user-guide.md) أو راسل **support@binjamshid.com**. عند الإبلاغ عن تصحيح في نصّ أو مرجع، اذكر الطبعة والموضع بدقة. استخدم بيانات تجريبية في البلاغات، وأرسل مسائل الخصوصية والأمان على البريد الخاص.
